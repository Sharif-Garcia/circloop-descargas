# CIRCLOOP · Descargas

App de devolución y recompensa de material reciclable de la Universidad Popular del Cesar.

## Android
**[Descargar CIRCLOOP](https://github.com/Sharif-Garcia/circloop-descargas/releases/latest/download/circloop.apk)**

1. Abre el enlace en el celular y descarga `circloop.apk`.
2. Ábrelo. Si Android lo pide, permite "Instalar apps desconocidas" para el navegador.
3. Entra con tu correo `@unicesar.edu.co`.

## iPhone
Usa la versión web: **https://circloop-f1a60.web.app**
En Safari: Compartir → "Agregar a pantalla de inicio".
